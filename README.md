# 💌 ¿Quieres ser mi San Valentín?

Una pequeña aplicación web interactiva creada con HTML, CSS y JavaScript para hacer una propuesta especial de San Valentín.

## ✨ Características
- **Botón escurridizo:** El botón de "NO" se mueve aleatoriamente cuando intentas pulsarlo, haciendo imposible rechazar la propuesta.
- **Diseño Responsive:** Se adapta a pantallas de ordenador y móvil.
- **Animaciones:** Transiciones suaves y efectos visuales.
- **Final Sorpresa:** Pantalla de celebración con GIF incluido.

## 🚀 Demo
¡Puedes ver el proyecto funcionando aquí! 👉​ https://batistamoni.github.io/interactive-javascript-ux-demo/

## 🛠️ Tecnologías utilizadas
- **HTML5:** Estructura semántica.
- **CSS3:** Flexbox, posicionamiento y diseño de tarjetas (Card Design).
- **JavaScript (Vanilla):** Manipulación del DOM y lógica matemática para el movimiento aleatorio.

## 📝 Cómo usar
1. Clona el repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. ¡Intenta pulsar el botón "NO"! (Spoiler: No podrás).
4. Pulsa "SÍ" para ver la sorpresa.
